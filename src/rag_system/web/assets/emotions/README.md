# 小绿表情资源

这些资源是 96×48 的像素风眼部动画，供工控机显示页和后续 ROS2 DisplayNode 使用。

## 使用方式

读取同目录的 `manifest.json`，根据状态名选择帧序列：

- `idle`：中性待机眼睛
- `listening`：正在听，交替眨眼
- `thinking`：正在思考，旋转螺旋
- `speaking`：正在回答，眨眼加腮红
- `success`：回答完成，星星眼
- `error`：异常或失败，出汗眨眼
- `sleep`：长时间空闲
- `shy` / `smug`：可选的个性化状态

每个状态的帧文件都以 `{state}_{序号}.png` 命名。素材使用纯黑底，渲染时应保持 `image-rendering: pixelated`，不要做平滑插值。

显示页以 `manifest.json` 的 `layout.eye_anchors` 作为待机眼睛中心，并把全部状态映射到同一屏幕位置，以 `content_bounds` 计算统一缩放比例。少数素材的原始眼睛中心不同（如 `thinking`），在对应状态的 `eye_anchors` 中单独标注。腮红、汗滴等装饰不参与眼睛定位，但会被完整保留在画面内；增改帧素材时应同步更新 `content_bounds` 和必要的眼睛锚点。

`idle` 当前使用开心素材中的普通眼睛帧作为中性待机占位。后续如果补充独立的普通眨眼素材，只需要更新 `manifest.json`，不需要修改显示逻辑。

## 内容情绪动画

`../display_tone.js` 提供与上述交互状态独立的八种内容情绪：开心、关切、难过、惊讶、
疑惑、害羞、自豪和鼓励。全部使用 96×48 的 Canvas 像素画，沿用相同眼睛锚点与安全
边界；开心的基础画面保留笑眼、四块粉色腮红的参考风格。无需替换原 PNG 帧。

每种情绪按 40 个时间步循环（每步 100 毫秒），包含与情绪对应的轻跳、抬眉、
泪滴、回弹、问号、腮红或星光变化，另有眨眼动作。显示页单独驱动时钟，所以
服务端状态保持不变时仍会持续运动；聆听、思考、报错、待机和网页模式停止此时钟。
单个动画最多缓存 40 张小画布，避免无限增长。

访问 `/display/preview` 查看动态预览并选择投到外接屏。`tone` 字段不等于旧素材的
`state` 字段，例如内容情绪 `shy` 与手动选择旧 `shy` PNG 状态分别独立。
