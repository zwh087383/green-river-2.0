## 启动状态

已用根目录 `一键启动小绿.bat` 启动替换后的项目，后台地址为 `http://127.0.0.1:8000/`。

验证时 Windows 仅识别到 `DISPLAY1`，因此未自动打开 HDMI 表情窗口。外接屏接入并设为扩展模式后，再运行一键启动文件即可打开表情窗口。
